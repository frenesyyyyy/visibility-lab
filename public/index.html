03 / Know what is measured

Evidence before
interpretation.

The same questions. A fairer comparison.

Every selected provider receives the same questions. The brand and aliases are checked locally against the answer body. Citation labels and link destinations do not count as mentions.

Sources you can inspect.

A measured answer must be complete, include search evidence and have citation markers that resolve to valid public web links. These checks do not prove a claim true or a page available. Read the sources before drawing conclusions.

Local by design.

No account, database or analytics. The server listens only on this computer. Prompts are sent to the providers you select; their data and billing policies apply. Export a run if you want to keep it.
